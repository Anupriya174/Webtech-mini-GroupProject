Project Description:
This project is a To-Do List and Productivity Tracker website. 
It allows users to create tasks, manage daily activities, and track productivity.
It also has Focus Timer which helps you to concentrate for certain amount of time
And it has a Pie Chart which tells the statistics about the daily activities .

Project Status:
This project is currently a partial implementation. 
This is a group project developed as part of a course assignment by three members.
In this project, I worked mainly on the overall project outline, the frontend structure, and a small part of the backend implementation.

Note:
This project was developed as a learning project. 
Some parts of the development were also assisted using AI tools such as ChatGPT for guidance and debugging.
